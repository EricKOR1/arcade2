# 아케이드 게임 시스템 — 설치 가이드

## 1. Firebase 프로젝트 만들기 (실시간 통신용, 무료)
1. console.firebase.google.com 접속 → "프로젝트 추가"
2. 프로젝트 이름 입력 후 생성 (Google 애널리틱스는 꺼도 됨)
3. 왼쪽 메뉴 "빌드 > Realtime Database" → "데이터베이스 만들기"
   - 위치는 아무거나, **테스트 모드**로 시작
4. 좌측 상단 톱니바퀴 > "프로젝트 설정" > 아래로 스크롤 > "앱 추가" > 웹(</>) 선택
5. 나오는 `firebaseConfig` 값을 복사해서 `firebase-config.js` 파일 안의
   `"여기에_..."` 부분에 그대로 붙여넣기

### 보안 규칙 (30일 후 테스트 모드가 자동으로 잠깁니다)
Realtime Database > 규칙 탭에서 아래처럼 바꾸고 게시하세요.
학급 활동용으로만 쓰는 임시 규칙이며, 아무나 읽고 쓸 수 있으니 참고하세요.

## 2. GitHub Pages로 배포하기 (무료)
1. GitHub에 새 저장소 생성 (Public)
2. 이 폴더 안의 파일을 모두 업로드
   - index.html (학생용), admin.html (교사용 대시보드)
   - style.css, shared.js, sound.js, games.js
   - tetris-engine.js, racing-engine.js (카트 레이싱)
   - firebase-config.js (본인 Firebase 값이 들어있는 파일)

UI 는 `style.css` 한 파일로 그립니다 (외부 CSS 프레임워크 없음). 별도 설치나 빌드 과정은 없습니다.
디자인 언어는 GitHub 스타가 가장 많은 UI 라이브러리 **shadcn/ui** 의 규격을 따릅니다 — zinc 중립 팔레트(배경 #09090b · 카드 #18181b · 테두리 #27272a),
버튼 높이 40 · 반경 8, 배지 알약, 카드 반경 12 + 1px 테두리, 포커스 링, 흐린 보조 텍스트. 게임별 강조색은 primary 로만 씁니다.
과학 게임 3종은 `platform.css` 가 원본 플랫폼의 모습을 그대로 재현합니다.
3. 저장소 Settings > Pages > Source에서 main 브랜치 선택 → 저장
4. 몇 분 뒤 `https://아이디.github.io/저장소이름/` 로 접속 가능

## 3. 사용 방법
- 학생용 주소: `.../index.html` → 이 주소를 QR코드로 만들어 배포
- 관리자용 주소: `.../admin.html` → 선생님만 들어가는 화면
- 관리자 화면에서 "게임 시작"을 누르면 대기 중인 학생 화면이 자동으로 테트리스로 전환됩니다
- "전체 초기화"를 누르면 다음 반 수업을 위해 명단이 비워집니다

## 다음에 게임을 추가하려면
1. 새 엔진 파일(예: `snake-engine.js`)을 만듭니다. 엔진에는 아래가 있어야 합니다.
   - `constructor(canvas, cellSize)`, `move(dir)`, `tick(now)`, `draw()`
   - `score`, `gameOver` 속성
   - `getSnapshot()` — 교사 화면 미니 보드용 숫자 2차원 배열
2. `games.js`의 `GAMES`에 항목을 추가합니다 (이름, 설명, cols, rows, controls, create).
3. `index.html`과 `admin.html` 아래쪽 `<script>` 목록에 새 엔진 파일을 추가합니다.

대시보드의 게임 카드와 QR은 자동으로 만들어지므로 admin.html은 더 손댈 필요가 없습니다.

### 레이저 태그 3D 화면 배치 (2026-10-06)
체력·탄약 카드(캔버스)와 조작 버튼(화면)이 따로 그려져 발사 버튼·조이스틱·줌 버튼과 겹쳤습니다(실제 브라우저에서 17건).
이제 학생 화면이 **버튼 위치를 재서 엔진에 알려 주고**(`setHudSafe`), 엔진이 빈자리에 카드를 놓습니다:
- 가로가 넉넉하면(가로 폰·일부 태블릿) **조이스틱 오른쪽 바닥에 나란히**, 좁으면(세로 폰) **조이스틱 위에 세로로**
- 구르기 쿨다운 링은 체력 카드 안으로. 줌 버튼은 스나이퍼일 때만 보이지만 자리를 미리 비워 둠
- 가로 모드 무기 칩은 옵션 버튼과 안 겹치게 재장전 옆 한 줄로 · 안내 문구는 화면 위쪽 가운데

- **타워 오르기** (2위 장르) — 그래픽: 밤하늘·별·도시 실루엣 배경, 리벳 박힌 강철 대들보, 나무 사다리, 나이테가 보이는 통, **픽셀아트 등반가**(서기·걷기·사다리 오르기·점프 4가지 모습, 바라보는 방향으로 뒤집힘), 빛나는 GOAL 깃발. 다섯 층 발판과 사다리. 꼭대기에서 통이 굴러 내려오며 가끔 사다리로 떨어집니다. 점프로 넘으면 +50, 꼭대기 GOAL 에 닿으면 다음 층. **난이도 곡선**: 1층은 통이 4초에 하나·느리게·사다리로 잘 안 내려오고, 층마다 조금씩 빨라집니다(첫 통은 3초 뒤)
- **미사일 방어** (6위) — 화면을 톡 누르면 그 자리에 요격탄이 **한 발** 터집니다(0.5초 커졌다 0.5초 줄어듦). 미사일이 지나갈 자리를 미리 누르는 게 요령. 파도마다 탄이 정해져 있고, 남은 도시·탄만큼 보너스. 3파도마다 도시 하나 복구
- **지네 사냥** (12위) — 버섯밭 사이로 지그재그 내려오는 지네. 맞은 마디는 버섯이 되고 지네는 둘로 갈라져 반대로 갑니다. 머리 100점, 버섯은 3발에 사라짐

### 2048 · 길 건너기 · 소행성
- **2048**: 밀어서 같은 숫자를 합칩니다. 2048 을 만들면 승리 표시, 더 못 움직이면 끝
- **길 건너기**: 차를 피하고 통나무를 타고 위쪽 다섯 집을 채우세요. 빨리 도착할수록 보너스, 다 채우면 다음 단계
- **소행성**: 화면 끝으로 나가면 반대편에서 나옵니다. 큰 소행성은 둘로, 다시 둘로 쪼개집니다

### 학생 개별 화면 보기 (교사)
관전 화면·아레나 지도·학생 카드 미니보드를 모두 **화면 배율 2배**로 그려 또렷합니다.
진행 중 화면에서 **학생 카드나 순위 줄을 클릭**하면 그 학생 화면이 크게 열립니다. ‹ › 로 다음 학생, Esc 로 닫기.
- 캔버스 게임: **학생 기기의 실제 화면**을 받아 보여 줍니다 (열어 본 학생만 480px JPEG 을 초당 약 7장 전송, 닫으면 멈춤). 도착하기 전 잠깐은 도식으로
- 카트 · 레이저 태그: **그 학생 시점의 3D 화면**을 엔진 관전 모드로 재생. 상대 카트는 받은 위치 두 개 **사이**를 0.15초 지연으로 보간(엔티티 보간)해 프레임 간 이동 변화 0.6%
- 과학 게임 3종: 화면이 학생 기기에만 있어 점수·진행만 표시

### 스네이크
**첫 방향키를 누를 때까지 움직이지 않습니다.** 먹이를 먹을수록 길어지고, 5개마다 속도가 한 단계 빨라집니다. 벽이나 자기 몸에 닿으면 끝.
십자 버튼 외에 화면을 상하좌우로 쓸어도 방향이 바뀝니다. 반대 방향으로는 꺾이지 않아요.

### 벽돌깨기
벽돌을 깨면 가끔(약 8%) 아이템 캡슐이 떨어집니다. 패들로 받으세요.
**멀티볼**(공이 셋으로, 최대 6개) · **넓은 패들** · **느린 공** · **목숨 +1** · **관통 공**(벽돌을 뚫고 지나감).
공이 여러 개일 때는 마지막 공을 놓쳐야 목숨이 줄어듭니다. 튕길 때마다 1.2% 빨라지되 기본 속도의 1.7배까지만.
패들의 어느 쪽에 맞느냐에 따라 튕기는 각도가 달라지고, 튕길 때마다 조금씩 빨라져요.
한 판을 다 깨면 다음 단계 — 벽돌이 늘고 패들이 좁아지며, 위쪽 줄은 두 번 맞아야 깨집니다.

### 하늘 날기
점프 버튼(또는 화면 탭)으로 날개짓. 기둥 사이 틈을 통과할 때마다 10점.
처음엔 틈이 넓고(7.8칸) 느리며 중력도 가볍습니다. 통과할수록 아주 서서히 어려워져 40개쯤에 본래 난이도가 됩니다.

### 우주 방어
적 무리가 좌우로 움직이다 벽에 닿으면 한 칸 내려옵니다. 적이 줄수록 남은 적이 빨라져요.
발사 버튼을 꾹 누르면 연사. 파도(wave)가 갈수록 적이 늘고 두 번 맞아야 죽는 적이 나옵니다.
적의 총알에 맞거나 적이 바닥까지 내려오면 목숨이 줄어요 (3개).

### 아케이드 게임을 더 만들려면
`snake-engine.js` 가 가장 짧은 본보기입니다. 엔진 클래스에 아래가 있으면 됩니다.

- `constructor(canvas, cellSize)`
- `tick(now)` · `draw()` — 매 프레임
- `move(±1)` · `rotate()` · `softDrop()` · `hardDrop()` — 버튼 이름에 맞춰 원하는 동작으로 연결
  (선택: `up()` `down()` `fire()` `jump()` `releaseSteer()`)
- `score` · `gameOver` 속성
- `getSnapshot()` — 교사 화면 미니 보드용 숫자 2차원 배열 (`shared.js` 의 `CELL_COLORS` 번호)

그 다음 `games.js` 에 항목을 추가하고, `index.html` · `admin.html` 아래쪽 `<script>` 목록에
엔진 파일을 넣습니다. `stats` 로 점수 옆에 보여 줄 수치 두 개를, `detail` 로 결과 화면 문구를,
`controls` 와 `labels` 로 버튼 구성을 정합니다.

## 과학 학습 게임 3종 (광합성 · 힘 · 몸속 여행)

원본 파일을 **한 줄도 고치지 않고** 그대로 씁니다. GAS 플랫폼이 제공하던
`App` 객체와 공용 CSS 를 아케이드 쪽에서 똑같이 재현했기 때문입니다.

### 올리는 방법
원본 파일 3개를 이름만 바꿔서 다른 파일들과 함께 저장소 최상위에 올립니다.

| 원본 | 올릴 이름 |
|---|---|
| 광합성 온실 관리자 | `photo.html` |
| 힘의 대결: 슈퍼 발사대 | `force.html` |
| 몸속 여행 | `body.html` |

파일은 학생이 그 게임을 고를 때만 내려받습니다. 대시보드 첫 화면은 가볍게 유지돼요.

### 무엇이 그대로인가
- 문항 은행, 그림, 물리 엔진, 소리, 점수 계산 — 게임 파일 안의 내용 전부
- 디자인 토큰(`--leaf` `--light` `--co2` 등)과 공용 컴포넌트(`.gamebar` `.card` `.res` …)
- 팝업(`App.overlay`), 순위표(`App.rankHtml`), 점수 저장(`App.submitAndRank`)

### 무엇이 바뀌었나 (게임 밖의 일)
- 서버 호출이 Apps Script → **Firebase** 로 바뀌었습니다
  - `saveScore` / `getBoard` → `scores/{게임}/L{단계}`
  - `roomJoin` / `roomState` / `roomPing` / `roomResume` → `rooms/{게임}/L{단계}`
- 로그인 대신 **아케이드 닉네임**이 학생 이름이 됩니다
- 게임의 "나가기"는 대시보드로 가는 대신 다시 시작 화면을 띄웁니다

### 몸속 여행 실시간 대결 켜는 법
1. 교사 화면에서 **몸속 여행**을 고르고 QR 배포 → **게임 시작**
2. 학생이 모드를 고를 때 **🏁 대결 참가**를 누르면 대기실로 들어갑니다
3. 교사 화면 상단 **실시간 여정 현황**에서 모드 탭을 고르고 **출발**을 누릅니다
   - 모두 완주하면 자동으로 끝나고, **마치기**로 중간에 끊을 수도 있습니다
   - 출발할 때마다 새 문제 세트 번호가 생겨 전원이 같은 문제로 겨룹니다

### 게임 화면 그대로 관전하기 (교사 화면)
**🎬 게임 화면으로 관전** 버튼을 누르면, 학생이 보는 그 화면 — 식도·위·심장·폐포·네프론이
움직이는 애니메이션 무대 — 를 교사 화면에 그대로 띄웁니다.

- 게임 자체를 교사 화면에 올리므로 **그림·효과·기관 애니메이션이 전부 그대로**입니다
- 카메라가 학생을 따라갑니다. **1등 자동** 또는 **학생 지목** 중 고를 수 있어요
- 다른 학생들은 게임이 원래 그리던 방식대로 같은 길 위에 이름표와 함께 나타납니다
- 문제 패널과 수치줄은 숨겨져 무대만 크게 보입니다
- **큰 화면** 버튼과 함께 쓰면 교실 앞 화면 전체를 무대로 채웁니다

교사 화면은 **방에 참가자로 끼지 않습니다.** 대기 인원·순위·점수판에 잡히지 않고,
교사의 점수도 저장되지 않아요. 모드 선택 → 대결 참가 → 출발도 자동으로 눌러 줍니다.

### 개요 지도 (관전을 끄면)
관전을 끄면 사람 도식 위에 기관과 여정을 표시한 개요 지도로 돌아갑니다.
학생이 어느 기관에 몇 명 있는지 한눈에 보기 좋고, 오른쪽에 실시간 순위가 함께 나옵니다.

### 교사 화면에서 보이는 것
학습 게임은 카트·테트리스와 달리 화면을 그대로 옮겨 보여 주지 않고,
**학생별 점수·단계·완료 여부 목록**으로 표시됩니다. 점수순으로 자동 정렬돼요.

## 조작법
### 테트리스
줄을 못 지워도 30초마다 한 단계씩 빨라집니다. 착지 예상 위치 표시는 없습니다.
- ← → : 좌우 이동 (길게 누르면 연속)
- ↻ : 회전 (벽에 붙어도 자동으로 밀어서 회전)
- ↓ : 누르는 동안 천천히 내려감 — 옆으로 밀어 끼워넣기 가능
- 바로 내리기 : 즉시 착지
- 화면을 좌우로 쓸어도 이동, 탭하면 회전, 아래로 쓸면 즉시 착지
- 착지 후 약 0.5초 여유가 있어 마지막에 옆으로 밀어 넣을 수 있습니다

### 카트 레이싱 (실시간 대전)
- ← → : 누르고 있는 동안 조향 (화면 좌/우 절반을 눌러도 됩니다)
- 아이템 사용 : 가지고 있는 아이템 발동
- ✕ 아이템 버리기 : 앞칸 아이템을 버리고 다음 상자를 받을 수 있게 함 (PC는 D 키)
- 자동 전진이라 가속 버튼은 없습니다
- 화면은 카트 뒤쪽 위에서 앞을 바라보는 3D 원근 시점입니다
- 트랙에 오르막·내리막이 있습니다. 오르막에서는 속도가 25~30% 떨어지고
  내리막에서는 20~30% 빨라집니다. HUD에 ▲ 오르막 / ▼ 내리막이 표시됩니다
- 트랙 밖으로는 나갈 수 없습니다. 벽에 긁히면 속도가 크게 줄어요
- 3바퀴를 먼저 도는 순서대로 등수가 매겨집니다

방향 안내
- 3D 시점이라 진행 방향이 그대로 앞쪽입니다
- 노면에 흰 화살표가 새겨져 있습니다. 항상 화살표 방향으로 달리세요
- 반대로 달리면 화면 가운데에 "역주행" 경고가 깜빡입니다
- 다음 코너가 가까워지면 화면 좌/우에 노란 화살표가 나타납니다
- 우측 미니맵에서 전체 코스와 모든 참가자 위치를 볼 수 있습니다
- 멀리 보이는 능선이 함께 흘러가 코너를 도는 감각을 줍니다

아이템 6종 (물음표 상자를 지나가면 룰렛이 돌아 하나 획득)
아이템은 최대 2개까지 보관됩니다. 사용 버튼을 누르면 앞칸(큰 슬롯)부터 나가고,
뒤칸(작은 슬롯)이 앞으로 당겨집니다. 2개가 차 있으면 상자를 지나가도 받지 않습니다.

- 🍌 바나나 : 뒤에 떨어뜨림. 밟으면 회전하며 미끄러짐
- ⚡ 부스터 : 2.2초간 가속
- 🚀 미사일 : 바로 앞 주자를 1.5초간 완전히 정지시킴
- 🌀 위치 교환 : 바로 앞 주자와 자리를 맞바꿈
- 🛡 방어막 : 8초간 모든 공격을 한 번 막아줌
- 🌩 번개 : 나보다 앞선 주자 전원을 1.8초간 감속

순위가 낮을수록 강한 아이템(위치 교환·미사일·번개)이 잘 나오고,
1등은 주로 바나나·방어막이 나옵니다. 뒤처져도 역전할 수 있는 구조예요.

트랙에는 파란 부스터 발판이 구간마다 하나씩 있습니다. 밟으면 자동 가속돼요.
발판은 흐르는 화살표와 양옆 빛기둥으로 표시되고, 가까워지면 HUD에
"부스터 발판 →" 알림이 뜹니다.

- 연석 색도 트랙마다 다릅니다 (도시는 하늘색, 사막은 주황, 설산은 파랑)

카트 4종 · 색 8가지

## 문제 해결

### 느릴 때
- 학생 기기는 닉네임만 담긴 `roster` 노드만 구독합니다. 전원의 보드·점수가 담긴 `players` 는 교사 화면만 받습니다 (예전엔 학생 30명이 서로의 보드를 초당 150번씩 받아 느렸습니다).
- 학생 화면은 배경 애니메이션과 반투명 블러를 쓰지 않습니다 (태블릿 GPU 부담). 캔버스 해상도 배율도 1.5배(카트 1.25배)로 제한됩니다.
- 상대 위치 신호는 프레임당 한 번으로 묶어 게임에 넘깁니다.
- 매 프레임 만들던 임시 객체를 돌려 써 가비지 수집으로 인한 순간 멈춤을 줄였습니다(프레임당 할당 34% 감소).
- 카트는 가까운 순서로 **정밀도 3단계**(정밀 입체 → 단순 입체 → 납작한 그림)로 그립니다. 30명이 출발선에 몰려도 무거운 조립은 앞쪽 몇 대에만 합니다 — 계산 시간 약 50% 감소.
- 카메라 각도·기울기·상대 위치 보간을 **프레임 간격에 맞춰** 계산합니다. 프레임 수가 달라져도 같은 시간에 같은 자리를 봅니다(60fps 와 30fps 카메라 경로 차이 0.48°).
- 위치 전송(0.165초마다)은 프레임을 그린 **뒤**에 합니다. 그리는 도중 끼어들어 멈칫하지 않습니다.
- 노면 화살표는 그려진 구간이 아니라 **인덱스로 직접** 찍습니다(멀수록 구간을 건너뛰어 깜박이던 문제).
- **스네이크**는 걸음 사이를 보간해 몸통이 한 칸씩 점프하지 않고 미끄러집니다. 새 그래픽: 머리와 사과는 **픽셀아트 스프라이트**(16×16 격자를 코드로 생성 — 외부 파일 없음, 저작권 문제 없음), 몸통은 **하나의 이어진 선**(외곽·본색·윗면 하이라이트 3겹 + 길이 기준 비늘)으로 그립니다.
칸 단위 조각을 이어 붙이면 기기 화면 배율이 소수점(예: 2.625)일 때 마디마다 경계선이 보여 그래픽이 깨진 것처럼 됩니다. 선 하나로 그리면 어떤 배율에서도 매끈합니다.
화면 반대편으로 넘어가는 구간만 끊어서 그립니다. 검증: 셀 27.6px · 배율 2.625 조건에서 몸통 위 배경색 픽셀 0개(이전 32개). **2048**은 타일이 120ms 동안 미끄러져 이동합니다.
- 도로 끝은 안개로 서서히 사라져, 멀리서 도로가 툭 나타나지 않습니다 (시야 거리도 1.5배).
- 게임 캔버스는 **불투명 모드**이고 그림자·둥근 모서리를 걸지 않습니다(매 프레임 합성 비용). 카트 HUD 는 값이 바뀔 때만 초당 15번까지 DOM 을 만지고, 이름표는 이미지로 캐시합니다.
- 터치 기기는 **중간 화질(배율 1.0)부터 시작**합니다.
- **적응형 화질**: 120프레임 평균이 21ms(48fps) 를 넘으면 자동으로 한 단계 낮춥니다(최고 → 중간 → 최저). 해상도 배율, 카트의 시야 거리·지물·입자, 3D 의 바닥 장식·원경이 줄어듭니다. 낮출 때 화면 위에 잠깐 알려 줍니다.
- 그래도 느리면 저사양 기기용 **레이저 태그 클래식**, 카트는 인원을 나눠 진행하세요.

### 새로 올린 파일이 반영되지 않을 때
학생 화면 맨 아래와 교사 화면 상단에 **v날짜** 표시가 있습니다.
이 값이 방금 올린 파일과 다르면 예전 파일이 캐시된 것입니다.

- PC: `Ctrl + Shift + R`
- 모바일: 주소 뒤에 `&v=2` 처럼 아무 값이나 붙여 접속
- 그래도 안 되면 브라우저 설정에서 사이트 데이터 삭제

### QR로 들어가면 대기 화면 없이 바로 게임이 시작될 때
지난 수업의 "진행 중" 상태가 남아 있는 것입니다.
교사 화면에서 **[대기실로 되돌리기]** 또는 **[게임 종료]** 를 누르세요.
학생은 게임 화면 오른쪽 위 **✕** 로 빠져나올 수 있습니다.

### 교사 화면 전체 보기
진행 중 화면의 **[⛶ 전체 화면 (학생 화면 보기)]** 를 누르면 다른 요소가 모두 사라지고
학생별 플레이 화면만 크게 펼쳐집니다. 교실 앞 화면에 띄우기 좋습니다. Esc 로 나옵니다.

### 연출
- 캔버스 게임 시작 시 **READY → GO!** (화면을 막지 않음). 카트·3D 는 자체 카운트다운
- 결과 화면: 점수가 **0 에서 차오르고**, 순위에 🥇🥈🥉 메달, 1위는 **색종이**
- 캔버스 가장자리 비네트로 깊이감. 숫자는 폭이 같은 글꼴로 흔들리지 않음
- **진동 피드백**: 피격·아이템·완주·오경보 때 아주 짧게 (지원 기기만, 소리를 끄면 함께 꺼짐)
- 전부 정적 합성이라 렉에 영향이 없습니다

### 대기 화면
게임 이름 · 한 줄 설명 · **조작 요약**이 카드로 보입니다. 팀전이면 자기 팀(🔴/🔵)도 미리 표시됩니다.
학생들이 기다리는 동안 조작법을 읽어 두면 시작 후 질문이 줄어듭니다.

### 벽돌깨기
그래픽: 입체 벽돌(윗면 광택·아래 그림자·테두리), 단단한 벽돌은 금 간 무늬, **공 꼬리 궤적**과 빛 번짐, 그립 무늬가 있는 패들(자석일 땐 자기장, 레이저일 땐 포신 표시), 격자 배경.
초반 공 속도가 30% 빨라졌고 아이템 낙하율도 50% 높였습니다(약 12.8%). 아이템 **9종**:
멀티볼 · 넓은 패들 · 느린 공 · 목숨 +1 · 관통 공 · **자석 패들**(공이 붙었다가 발사로 다시 쏨) · **큰 공** · **레이저**(발사 버튼으로 위로 쏨) · **작은 패들**(함정).
화면 왼쪽 위에 지금 켜져 있는 효과가 아이콘으로 표시됩니다.

### FPS 조작 배치
오른쪽 조작은 층으로 나눠 서로 겹치지 않습니다: 발사(맨 아래) · 점프/구르기 · 재장전 · 무기 칩. 가로 모드도 같은 순서로 축소 배치됩니다.

### 조작 패드
상하좌우가 다 있는 게임(미로 추격·타워 오르기·스네이크·2048·길 건너기)은 **왼쪽에 십자 D-패드**(네 방향 같은 크기·같은 거리), 오른쪽에 특수키(점프). 특수키가 없으면 D-패드가 가운데로.
테트리스는 회전과 '바로 내리기' 사이에 ↓ 를 넣고 간격도 띄워 잘못 누르지 않게 했습니다.
좌우 이동만 있는 게임은 **← 가 맨 왼쪽, → 가 맨 오른쪽**에 크게 놓이고, 회전·↑↓·발사·아이템은 가운데 세로로 쌓입니다 (양손 엄지).
하늘 날기처럼 방향키가 없으면 점프가 가운데, 3D 레이저 태그는 조이스틱 + 조준 드래그 + 발사입니다.

### 수업 중 게임 바꾸기
두 가지가 있습니다.

- **[게임 바꾸기]** — 게임 선택 화면으로 돌아갑니다. 학생은 대기실에서 기다리고, 게임을 고른 뒤 [게임 시작] 을 눌러 시작합니다.
- **[⇄ 모두 다른 게임 대기실로 이동]** — 게임(카트는 트랙까지)을 고르면 **모든 학생 화면이 그 게임의 대기실로** 옮겨집니다. 조작법을 읽을 시간을 준 뒤 [게임 시작] 을 누르세요.

어느 쪽이든 명단과 닉네임은 유지됩니다.

교사 화면에서 **[게임 바꾸기]** → 원하는 게임 카드를 누릅니다.
들어와 있는 학생이 있으면 확인 창이 뜹니다.

- **확인** — 학생 화면이 곧바로 새 게임으로 넘어가 바로 시작합니다
- **취소** — 새 게임 대기실에서 기다렸다가 [게임 시작] 을 눌러 시작합니다

어느 쪽이든 **명단과 닉네임은 그대로 유지**됩니다. 학생은 QR을 다시 찍을 필요가 없습니다.
명단을 정말 비우려면 **[명단 비우기]** 를 쓰세요.

### 뒤로가기
학생 화면 왼쪽 위에 **←** 버튼이 있습니다. 휴대폰의 뒤로가기 제스처도 같은 동작을 합니다.

| 현재 화면 | 뒤로 가면 |
|---|---|
| 대기 | 닉네임 |
| 게임 · 학습 게임 | 대기 (게임은 멈춤) |
| 결과 | 대기 |
| 닉네임 · 종료 | 버튼 없음 (페이지가 닫히지 않습니다) |

첫 화면에서 뒤로가기를 눌러도 페이지가 나가지 않고, 게임 중에 탭을 닫으려 하면 확인 창이 뜹니다.

### 플레이 중 튕겼을 때
학생이 다시 접속하면 **자동으로 명단에 복구**되고 게임도 이어집니다.
새로고침되어 닉네임 화면이 나와도 이름이 미리 채워져 있어 한 번만 누르면 됩니다.

"수업이 끝났습니다" 화면에서는 **[다시 참여하기]** 를 누르세요.
선생님이 대기실로 되돌리거나 다시 시작하면 버튼을 누르지 않아도 자동으로 넘어갑니다.

### 게임을 강제로 끝내야 할 때
교사 화면 진행 중 상태에서 **[강제 종료]** 를 누릅니다 (확인 창이 뜹니다).

| 버튼 | 하는 일 |
|---|---|
| 대기실로 되돌리기 | 게임만 멈추고 대기실로. 명단·점수 유지 |
| 게임 종료 | 종료 화면 표시. 판 위 데이터는 남음 |
| 강제 종료 | 즉시 종료 + 주행 위치·아이템·대결방 초기화. 명단은 유지되고 학생은 바로 다음 판 참여 가능 |

### 학생이 대기 명단에 안 뜰 때
화면 위 빨간 띠에 이유가 표시됩니다.

| 띠 문구 | 해결 |
|---|---|
| 설정이 비어 있습니다 | `firebase-config.js` 를 Firebase 콘솔 값으로 채우기 |
| 규칙에 막혀 저장이 안 됩니다 | 콘솔 > Realtime Database > 규칙 을 `{ "rules": { ".read": true, ".write": true } }` 로 게시 (기본 규칙은 30일 뒤 만료) |
| 연결되지 않았습니다 | `databaseURL` 확인, 학교 방화벽 확인 |

띠가 없는데도 안 뜬다면, 학생이 닉네임을 넣고 **[입장하기]** 까지 눌렀는지 확인하세요.
